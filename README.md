## **☆ Описание системы**

Этот проект - серверное приложение на Node.js с использованием Express, MongoDB и JWT для аутентификации пользователей (студентов и преподавателей).

Проект предоставляет API для:

- **регистрации и авторизации пользователей**;
- **получения данных о пользователях и их удаления**;
- **загрузки и обработки изображений с наложением водяного знака;**
- **создания курсов, получение данных и их удаления**;
- **создание уроков к курсам, получение данных и их удаления**;
- **возможность комментировать урок, обновлять комментарий и удалять**.

---

## **☆ Установка приложения**

### _1. Клонировать репозиторий:_

```bash
git clone https://github.com/your-username/project-name.git
cd project-name
```

### _2. Установить зависимости:_

Введите команду для установки зависимостей с помощью **npm**:

```bash
npm install
```

Либо же, пропишите:

```bash
npx yarn install
```

При этом устанавливаются все необходимые пакеты, подтвержденные в файле package.json.

### _3. Настроить .env файл:_

В корне проекта создайте файл **.env** и добавьте следующие строки:

```bash
MONGO_URI=mongodb://127.0.0.1:27017/mongo
JWT_SECRET=your-jwt-secret-key
PORT=6000
```

где:

- **MONGO_URI** - строка подключения к MongoDB.
- **JWT_SECRET** - секретный ключ для JWT аутентификации.
- **PORT** - порт для запуска сервера.

### _4. Запустить MongoDB:_

Если у вас установлен MongoDB локально, запустите его:

```bash
mongod
```

Или используйте Docker для MongoDB:

```bash
docker run -d -p 27017:27017 --name mongo-container mongo
```

## **☆ API: загрузка изображений**

- **POST /upload** - загружает изображение, сжимает и накладывает водяной знак

**Результат:** URL обработанного изображения в JSON-ответе.

**Обязательно наличие файла watermark.png в директории public/**

#

## **☆ API: Пользователи**

- **POST /register** — регистрация пользователя (студент или преподаватель)
- **POST /login** — вход в систему, вернет токен
- **GET /me** — получение данных текущего пользователя
- **GET /users** — получение всех пользователей
- **DELETE /users/:id** — удаление пользователя

#

## **☆ API: Курсы**

- **POST /courses** — создание курса (только преподаватель)
- **GET /courses** — получение всех курсов
- **GET /courses/:id** — получение курса по ID
- **DELETE /courses/:id** — удаление курса (только преподаватель)

#

## **☆ API: Уроки**

- **POST /lessons/:courseId** — добавить урок в курс (только преподаватель)
- **GET /lessons/:courseId** — получить список уроков по курсу
- **GET /lessons/:lessonId** — получить урок по ID
- **DELETE /lessons/:lessonId** — удалить урок (только преподаватель)

#

## **☆ API: Комментарии**

- **POST /comments/:lessonId** — добавить комментарий к уроку
- **GET /comments/:lessonId** — получить комментарии к уроку
- **PUT /comments/:commentId** — обновить комментарий
- **DELETE /comments/:commentId** — удалить комментарий

#

## **☆ Авторизация**

Все защищённые маршруты требуют JWT токен в заголовке:

```http
Authorization: Bearer <ваш_токен>
```

## **☆ Запуск приложения**

После установки зависимостей и настройки .env файла, запустите сервер:

```bash
npm run dev
```

Или с использованием yarn:

```bash
yarn run dev
```

```bash
npx yarn run dev
```

Поздравляю! Приложение будет доступно по адресу http://localhost:6000

## **☆ Обработка ошибок**

Сервер использует стандартный код ответа HTTP для обработки ошибок:

- **400 Bad Request** — файл не передан.
- **401 Unauthorized** - если токен не был предоставлен или токен недействителен.
- **404 Not Found** - если ресурс не найден.
- **500 Internal Server Error** - если произошла ошибка на сервере.
